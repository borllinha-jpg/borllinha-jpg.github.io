Política de privacidad

Hyrox uploader es una herramienta de uso personal. Esta política explica cómo trata los datos de Google.

Datos a los que accede

Solo solicita el permiso https://www.googleapis.com/auth/youtube.upload, que sirve para subir vídeos al canal de YouTube del propietario de la cuenta.

Uso de los datos

  • El token de acceso se guarda únicamente en el ordenador del propietario (archivo local) y se usa solo para subir vídeos.
  • No se recopilan, venden ni comparten datos personales con terceros.
  • No se usan servidores externos: todo se ejecuta en local.

El uso de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado. También se aplican las Condiciones del servicio de YouTube y la Política de privacidad de Google.

Revocar el acceso

Puedes retirar el permiso en cualquier momento desde myaccount.google.com/permissions. Al hacerlo, el token local deja de funcionar.
